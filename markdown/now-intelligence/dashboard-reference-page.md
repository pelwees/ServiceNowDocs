# Dashboard reference

Reference topics provide a list of roles and translatable fields for Platform Analytics dashboards.

-   **[Translatable fields in dashboard elements](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/now-intelligence/../../performance-analytics/concept/translatable-fields-dashboard.md)**  
For fields that show the **Translatable turned on** badge, you can add translations of the field value in the Messages \[sys\_ui\_message\] table.
-   **[Platform Analytics dashboard roles](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/now-intelligence/pa-dashboard-roles.md)**  
Platform Analytics dashboards have few role restrictions. Editing rights are granted by sharing, independent of role.
-   **[Platform Analytics dashboard tables](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/now-intelligence/../reference/par-dashboard-tables.md)**  
The following tables relate to Platform Analytics dashboards and can be accessed through scripts.
