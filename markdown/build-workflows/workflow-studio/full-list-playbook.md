# Open full lists within a playbook

Open a full list within playbook cards to view and update list items.

To open a full list within a playbook, click the **Open List** icon \(![Open list icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/build-workflows/workflow-studio/../image/playbook-open-list.png)\).

![Playbook card displaying a Open List button](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/build-workflows/workflow-studio/../image/playbook-open-list-card.png "Card view")

A new tab opens to show a full list. ![Full list tab.](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/build-workflows/workflow-studio/../image/playbook-list-tab.png)
