# Use prompt assistance

Use prompt assistance to get a jump start with your prompt development by selecting an example from the prompt library or using Now Assist to generate one.

## Before you begin

Role required: sn\_skill\_builder.admin

## Procedure

1.  Navigate to **All** &gt; **Now Assist Skill Kit** &gt; **Home**.

2.  Create a new skill or select the skill that you want to use prompt assistance for.

3.  Select the prompt assistance icon.![Prompt assistance icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/intelligent-experiences/now-assist-skill-kit/../image/icon-nask-prompt-assistance.png)

4.  Select the **Library** tab to search for a prompt from the prompt library.

5.  ![Prompt assistance prompt library search panel](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/intelligent-experiences/now-assist-skill-kit/../image/nask-pa-library.png)

6.  Select the **AI generated** tab to have AI help you create a prompt based on your needs.

    ![Prompt assistance AI generated panel](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/intelligent-experiences/now-assist-skill-kit/../image/nask-pa-ai.png)
