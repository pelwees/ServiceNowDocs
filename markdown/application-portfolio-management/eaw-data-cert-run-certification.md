# Run certification for a policy

Run certification for published policies to generate a new certification instance for an active policy.

## Before you begin

Role required: sn\_apm.apm\_analyst

## Procedure

1.  Navigate to **Workspaces** &gt; **Enterprise Architecture Workspace**.

2.  Open the Data certification page by selecting the Data certification icon \(![data certification icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/application-portfolio-management/../../image/eaw-image/icon-data-cert.png)\).

    The Data certification page opens.

3.  Select the check box next to the policy that you want to run certification for.

4.  Select **Run certification** from the context menu or use the **Run certification** button on the page.

    ![Run certification](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/application-portfolio-management/../../image/eaw-image/eaw-data-cert-run-cert.png)

5.  Select **Run**.

    A confirmation message appears with a link to track the progress.![Link to track certification status](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/application-portfolio-management/../../image/eaw-image/eaw-data-cert-track-status.png)

6.  Select the Track progress link or select the Track progress tab to see the status.
