# Task resources

Resources are the individuals or groups assigned to perform tasks and subtasks in Project Management.

You can use Resource Management to [set up resource plans](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/it-business-management/project-management/../../resource-management/task/t_CreateResourcePlanProjectTask.md), which can be associated with projects. Activate [Project Portfolio Management](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/it-business-management/project-management/../../project-portfolio-suite/concept/c_ProjectPortfolioSuite.md) to use Resource Management with Project Management.
