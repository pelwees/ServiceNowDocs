# Form headers for UI versions

Core UI and UI15 each have a different form header that offers different navigation icons.

Learn about form header navigation by selecting the form header topic that corresponds to the UI version your organization uses.

**Parent Topic:**[Forms in the classic environment](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/c_UsingForms.md)

## Core UI form header

The form header displays the title of the form \(table\) and provides several controls.

The Core UI form header includes the following controls.

![Form header Core UI](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../image/FormHeaderUI16.png "Form header Core UI")

|Control|Icon|Description|
|-------|----|-----------|
|Back|![back icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../image/FormBackUI15.png)|Navigates to the previously viewed page without saving changes.|
|Form context menu|![form context menu icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../../../administer/navigation-and-ui/image/MenuIconUI14.png)|Appears when a user clicks the menu icon beside the form title or right-clicks the form header. This menu is also called a right-click menu.|
|Attachments|![attachments icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../image/FormAttachmentsUI15.png)|Allows users to view and add attachments to the record. For more information, see [Add and manage attachments](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../task/t_AddingAnAttachment.md).|
|Show activity stream|![show activity stream icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../image/FormLiveFeedUI15.png)|Moves focus to the journal entry section of the form. If the journal fields are not on the form, the activity stream opens in a fly-out window.|
|Personalize form|![personalize form icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../image/Personalize_Form_Icon_Helsinki.png)|Opens the form personalization menu. For more information, see [Personalize a form](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../task/t_PersonalizeAForm.md).|
|More options![More options icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../image/IconUI16MoreOptions.png)|
|Email|![email icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../image/FormEmailUI15.png)|Opens an email window.|
|Template bar|![edit tags icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../image/IconToggleTemplateBar.png)|Opens a bar at the bottom of the form and lists available templates.|
|Annotations|![annotations icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../image/FormToggleAnnotUI15.png)|Displays on-form annotations. For more information, see [Administering form annotations](https://raw.githubusercontent.com/ServiceNow/ServiceNowDocs/australia/markdown/platform-administration/c_FormAnnotation.md).|
|Tags|![edit tags icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../image/FormEditTagsUI15.png)|Displays the option to create custom tags and categorize documents. For more information, see [Tags](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../../common-ui-elements/concept/c_Tags.md).|
|Remaining controls|
|Submit or Update| |Saves changes and returns to the previously viewed page.|
|Related actions| |Provides standard actions in the form header for some tables, such as Close Incident or Resolve Incident in incident.|
|Delete| |Deletes the record from the list.|
|Previous and Next|![previous icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../image/FormPreviousUI15.png) ![next icon](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/platform-user-interface/../image/FormNextUI15.png)|Opens the previous and next record on the list from which the record was accessed.|
