# Create a user criteria record

Add a user criteria record to decide which users, roles, and groups can access a reservable module.

## Before you begin

Role required: sn\_wsd\_rsv.admin

## Procedure

1.  Navigate to **All** &gt; **Workplace Reservation Management** &gt; **Administration** &gt; **User Criteria**.

2.  Click **New**.

3.  On the form, fill in the fields.

    For a description of the field values, see [User criteria form](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/employee-service-management/workplace-reservation-management/../reference/user-criteria-form.md).

4.  Click **Submit**.


## Result

The user criteria is added to the application.
