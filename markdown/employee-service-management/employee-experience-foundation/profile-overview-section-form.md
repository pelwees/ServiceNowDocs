# Overview section form

The overview section form enables you to configure a section on the Employee Profile UI.

<table id="table_vdm_zcw_rqb"><thead><tr><th>

Field

</th><th>

Description

</th></tr></thead><tbody><tr><td>

Name

</td><td>

Unique name that identifies the section. For example, About and Personal information.

</td></tr><tr><td>

Layout

</td><td>

Layout determines how the section content is displayed:-   Single Column: Displays the content in a single column layout.
-   Two Column: Displays the content in a two-column layout.

</td></tr><tr><td>

Hide section name

</td><td>

Display settings for the section name.

</td></tr><tr><td>

Application

</td><td>

Domain to which the section belongs to.

</td></tr><tr><td>

Order

</td><td>

Order in which the section is displayed.

</td></tr><tr><td>

Active

</td><td>

Option that indicates if the section content is active or not.

</td></tr><tr><td>

Section visibility

</td><td>

Visibility settings for the section:-   Mobile only
-   Desktop only
-   Desktop and mobile

</td></tr></tbody>
