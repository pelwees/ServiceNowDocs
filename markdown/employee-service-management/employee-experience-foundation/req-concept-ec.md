# Enhanced Requests Experience forms

The forms provide information to set up the Enhanced Requests Experience.

-   **[Request source form](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/employee-service-management/employee-experience-foundation/request-source-form.md)**  
The field descriptions provide a reference point when you're creating a request source.
-   **[Request filter definition form](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/employee-service-management/employee-experience-foundation/filter-def-request-form.md)**  
The field descriptions provide a reference point when you're creating a Requests filter definition.
-   **[Request filter configuration form](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/employee-service-management/employee-experience-foundation/filter-config-form-req.md)**  
The field descriptions provide a reference point when you're creating a Requests filter configuration.
-   **[Request filter condition form](https://raw.githubusercontent.com/pelwees/ServiceNowDocs/australia/markdown/employee-service-management/employee-experience-foundation/filter-cond-form-req.md)**  
The field descriptions provide a reference point when you're creating a Requests filter definition.
